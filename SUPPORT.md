# Support Resources for NoticeSync

Thank you for using NoticeSync. We want to ensure you have the resources you need to deploy, integrate, and use NoticeSync effectively.

## Documentation and Guides

- [README.md](README.md): Architecture overview, system design, local quickstart, and configuration.
- [Security Policy](SECURITY.md): How to securely disclose vulnerabilities.
- [Contributing Guidelines](CONTRIBUTING.md): Code standards, branching model, and test requirements.
- [Accessibility Statement](ACCESSIBILITY.md): Assistive technology support, compliance targets, and barrier reporting.

## Asking Questions and Getting Help

- **GitHub Issues**: Use our [Bug Report](.github/ISSUE_TEMPLATE/bug_report.md) or [Feature Request](.github/ISSUE_TEMPLATE/feature_request.md) templates for reproducible bugs or feature enhancements.
- **Repository**: [NoticeSync on GitHub](https://github.com/KatkamKoushik/NoticeSync)

## Security Vulnerabilities

If you believe you have discovered a security vulnerability, please do not file a public issue. Follow the private disclosure procedure outlined in [SECURITY.md](SECURITY.md).
